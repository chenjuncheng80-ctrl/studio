Connect your GitHub repo

Content is stored as files in your repository. Publishing pushes one commit and Vercel rebuilds the site.

  1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Name it anything, set expiration as you like, and under Repository access pick Only select repositories → studio.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token, paste it below.

The token stays in this browser (localStorage). Nothing is sent anywhere except api.github.com.
